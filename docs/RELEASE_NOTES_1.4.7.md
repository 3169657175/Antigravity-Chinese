# AGY Hub 1.4.7

适用平台：Windows 10 / 11。补丁构建基线：Antigravity 2.34.0。

- 修复新版注入失败：识别带登录引导的窗口加载入口，保留官方 BaseWindow、WebContentsView 和令牌引导流程。
- 修复 2.34.0 启动注册新增返回值后，注入账号接口被放在 `return` 后而不执行的问题；账号列表、实时额度和内部切换桥接在独立函数中显式注册，保留官方返回的窗口控制器。
- 修复注入侧栏与账号详情额度不刷新：当前账号直接调用 Language Server 的结构化额度接口，启动、定时刷新和手动刷新共用同一条查询与推送流程。
- 避免旧二进制扫描跨额度桶读取；正确显示 0%，淘汰旧解析器缓存，并阻止账号切换前的响应覆盖新账号。
- 修复小助手账号导出、导入缺少后端处理函数；小助手与注入账号窗口共用文件处理模块。导入凭据加密保存，同邮箱更新保留账号 ID，不主动切换账号。
- 无效账号 ID、损坏或缺少凭据的文件会返回明确错误；导出解密失败时停止，不生成不可迁移的伪成功文件。

安装新版 AGY Hub 后，点击“注入中文汉化补丁”以更新 Antigravity 中的侧栏和账号窗口。安装包更新本身不会替换已运行客户端的注入代码。

当前交付不包含自动登录或替换账号操作。未知后续客户端结构仍会在写入前校验并安全停止。
