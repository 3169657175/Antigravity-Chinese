# AGY Hub v1.4.3 · 智能额度、Gemini 4 Argon 与社区体验升级

> 发布日期：2026-10-24 · 适用平台：Windows 10 / 11 · 汉化补丁当前基于 Antigravity 2.26.0 验证

本次更新重点解决 **Gemini 4 Argon 离线无法实时查询、账号切换异常、反代模型列表过时** 等问题，同时继续改进汉化适配、社区反馈和桌面界面。

## ✨ 核心更新

### 1. Gemini 4 Argon 独立额度：支持纯云端查询
- 使用已保存账号的 OAuth 授权，直接向 Cloud Code 查询额度，**无须启动 Antigravity、无须切换到目标账号**。
- 兼容新的只读额度请求：对相关接口使用 CLI 客户端标识和空 JSON 请求体；旧桌面端查询方式作为回退。
- 分别查询每日/生产两个 Cloud Code 主机的额度摘要、模型额度和可用模型目录。
- 独立识别 `gemini-argon-wtu-weekly`，显示真实剩余额度和重置时间；查询失败时明确标记为待确认或历史数据，不把缓存误报成实时额度。
- 各账号额度、模型权限与缓存互相隔离；没有授权过的账号仍需先正常登录并保存凭据。

### 2. 账号切换与多账号体验
- 调整小助手与 Antigravity 内置账号窗口的切换协作机制，减少直接操作凭据和不正确重启导致的“切换后回到登录页”。
- 加入请求确认、失败保护和账号状态同步；对未完成的切换提供明确反馈。
- 优化多账号额度刷新、异步结果防串号以及快速切换后的界面状态。

### 3. 反代模型目录与 Codex / API 接入
- 模型列表根据**所选账号实际返回**的云端模型目录生成，不再在所有账号上展示相同的固定列表。
- 对获得授权的账号识别 Gemini 4 Argon High / Medium / Low 与 Claude 5.5 型号；其他账号继续展示其实际可用的 Gemini 3.8 Flash、Claude 4.6 等模型。
- 改进 Codex 私有模型别名映射和 API 模型发现，避免跨账号沿用错误模型；保留 OpenAI Responses、Chat Completions、Anthropic Messages、Gemini Native 四套协议。
- 调整“配置快照 / 请求时间线 / 一键诊断”按钮的间距、对齐与窄窗口响应式布局。

### 4. 汉化补丁与社区
- 继续支持一键汉化、按当前官方版本重新构建、备份回退和还原英文原版；对未知客户端结构采用校验失败即停止的策略。
- 完善 Antigravity 内嵌账号窗口与小助手的额度展示一致性。
- 优化社区反馈、评论和回复的加载与提交状态；改善深色与浅色主题的视觉一致性。
- 反馈和公告支持图片/粘贴等交互；管理界面继续提供用户、公告和反馈处理能力。

## 🔐 隐私与注意事项

账号授权信息供本机额度查询和账号操作使用；普通额度查询不发送聊天内容，也不调用模型生成。请不要向他人提供账号导出的配置、Token 或 API Key。模型列表与额度可因账号权限、Google 上游调整及网络环境不同而变化。

**反馈问题时建议提供：** AGY Hub 版本、Antigravity 版本、相关页面截图（遮盖邮箱/Token），以及「活动日志」中的非敏感错误信息。
