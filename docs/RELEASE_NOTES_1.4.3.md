# AGY Hub 1.4.3

发布日期：2026-10-24

## 新增与改进

- 账号额度查询改为本机语言服务优先、两个官方 Cloud Code 主机只读补充。云端缺失不会覆盖已经由本机确认的真实额度，也不会切换当前账号、Provider、模型或网关模式。
- Gemini 4 Argon 按账号独立识别。本机返回真实 Argon bucket 时展示额度；只有云端模型证据但没有数值时显示“待确认”；没有证据的账号不会继承其他账号的状态。
- 增加语言服务启动重试、账号隔离短缓存、账号切换失效和异步结果防串号，降低启动阶段偶发探测失败及多账号数据串用。
- 注入窗口与 AGY Hub 共用额度判定和模型证据逻辑，多账号窗口、侧栏额度与本地账号页保持一致。

## 修复

- 修复“反代接入”页面顶部“配置快照 / 请求时间线 / 一键诊断”按钮纵向堆叠的问题；桌面宽度下保持横向排列，小窗口自动换行。
- 移除反馈页右上角没有必要的“离线只读”提示，后台同步继续静默执行。
- 修复回复已成功送达后仍显示“发送中”的状态残留；提交成功会立即更新本地状态，并在服务端详情回读后完成对账。
- 修复额度接口缺字段时被误判为 0% 或 100%、旧请求覆盖新请求以及账号切换后沿用前一账号 Argon 状态的问题。

## 发布质量

- 新增并扩展额度、Argon 账号切换、CLI 网关、反馈详情、社区 UI、覆盖安装、成品补丁和动态汉化回归测试。
- 发布门禁校验 `main.js`、`preload.js`、`ipcHandlers.js` 语法、`accountVault.js` 完整性、源码/构建/部署补丁哈希一致性，并保留上一份已验收安装文件用于回退。
- 1.4.3 发布构建共执行 301 项测试：298 项通过、3 项按环境跳过、0 项失败；覆盖安装、成品补丁和动态汉化冒烟验证均通过。
