# AGY Hub 1.4.4

发布日期：2026-10-26

## 反代账号与模型路由

- 反代页的账号下拉框、当前账号提示和额度卡片统一使用同一份账号草稿状态；选择账号后立即切换展示，不再等待后台刷新后才更新。
- 额度响应携带账号标识并使用请求序号防止竞态，旧请求无法覆盖用户刚选中的账号，也不会在刷新后随机显示其他账号。
- 按账号保存真实可用模型目录。Gemini 4 Argon、Claude 与 Gemini 常规模型分别根据所选账号的能力和动态模型映射路由，不再共用错误的全局额度桶或旧目录。
- 三级测试沿用当前选中的账号与模型，并把账号信息传入诊断链路，避免测试时悄悄切换路由。

## 界面与交互

- 反馈页移除冗余顶部说明，搜索框增加合理内边距，反馈数量使用统一徽标排版。
- 用户管理与公告页同步统一搜索框、数量和摘要样式，窄窗口下保持对齐与可读性。
- 延续并打包 1.4.3 已完成的公告常驻入口、新公告首次主动弹出、更新下载重试、Markdown 更新说明渲染和账号额度隔离修复。

## 发布质量

- 发布构建执行补丁重建、补丁完整性校验、全量自动化测试、覆盖安装测试、安装包资源一致性检查及成品动态汉化验证。
- 发布门禁要求 `dist/main.js`、`dist/preload.js`、`dist/ipcHandlers.js` 语法通过，补丁包含 `dist/accountVault.js`，并核对源码补丁、构建补丁与安装包外置补丁 SHA-256 一致。
- 1.4.3 已验收 ASAR 和发布文件在构建前独立备份，1.4.4 构建失败时可回退。
