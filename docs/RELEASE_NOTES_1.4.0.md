# AGY Hub 1.4.0

## 修复内容

- 修复部分汉化在动态页面中消失：React 移除分片扫描当前节点后会导致遍历提前结束，现在恢复遍历，保留每批 250 节点 / 6ms 限制。`No Project`、输入提示、`Turbo`、`Settings` 均在 Chromium 动态渲染回归中验证；聊天内容、输入文字、项目名和代码保持原文。发布门禁新增实际成品汉化引擎的 DOM 测试。
- 修复新版自动适配时读取 Hub ASAR 内 `accountQuota.js` 失败，改为外置运行资源，并保留 Hub 自身需要的模块。成品门禁校验主包、外置资源、汉化包中的额度代码一致。
- 额度修复同步到注入窗口。4 个真实账号的成品 Hub 和动态注入包额度接口都完整返回 Gemini / Claude 的 5 小时与每周额度，未切换账号或修改接入配置。
- 修复注入后客户端版本暂时显示 `unknown`：通过物理文件快照读取版本，避免 Electron ASAR 缓存与 `noAsar` 状态影响；失败的客户端读取也不会遮住补丁版本。页面立即刷新用户选定的客户端。
- 按版本、官方文件哈希与结构自动构建补丁。同版本号的官方重打包也会重新适配；重复注入使用经过验证的同版本官方备份，不把旧版官方文件覆盖到新版。
- 保留安装升级时的自动关闭、官方原版备份、上一版汉化回滚、主题、账号、反代和 Token 功能。

## 验证范围

- 当前正式官方基线：Antigravity 2.24.0。
- 单元及回归测试：277 项，274 通过，0 失败，3 项可选 MCP 实机测试跳过。
- 安装器：7 项独立身份的安装升级测试通过，包括 1.3.9 → 1.4.0、同版本重装、自动退出和强制关闭兜底。
- 实际成品 Worker：5 项通过，包括 2.24.0 官方副本注入、模拟 2.25.0 与 CRLF 换行、重复注入、同版本文件变化、缺少必要结构时拒绝写入。
- 成品页面：注入测试副本后立即显示 `v2.24.0 / v1.4.0`，无需重启 Hub。
- 成品汉化引擎：Chromium 中连续移除 3,000 个列表节点后，四处固定控件仍能完成汉化；后续重新渲染也可翻译，聊天内容、输入文字、项目名和代码保持原文。

模拟新版本只用于证明没有写死版本号，不代表测试了尚未发布的客户端。未来版本若改变必要结构或能力，会在关闭客户端和写入前明确报错；无法承诺任意未知版本无条件兼容。

## 安装与升级

1. 下载并运行本页附件 `agy-hub-setup-1.4.0.exe`，支持覆盖安装。
2. 打开 AGY Hub，点击“注入中文汉化补丁”应用新版。
3. 如需回退，使用“退回上一版汉化”或“还原官方英文原版”。

此版本包含动态页面汉化遗漏的修复。安装包 SHA-256：

```text
e69fc48a348073d4a1d123700d49d2b4abfc6907b33adafad142a2254f9dd022  agy-hub-setup-1.4.0.exe
```

附件 `latest.yml` 和 `.blockmap` 用于应用自动更新，手动安装只需下载 `.exe`。
