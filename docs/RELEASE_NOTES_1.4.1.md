# AGY Hub 1.4.1

## 额度识别与显示

- 额度卡片新增三态判定：查询完成前显示“正在查询实时额度”，两个官方主机均确认缺失后隐藏对应额度；部分主机失败时保留“待确认”，避免把网络延迟误判成没有额度。
- Gemini 每周额度若未由上游返回，不再显示 `--` 空进度条，只显示仍可验证的 5h 额度。
- 额度接口恢复 Antigravity 官方客户端标识，避免上游裁掉 `gemini-weekly` 与 `gemini-5h` bucket。
- 当前账号从本机语言服务只读合并 `gemini-argon-wtu-weekly`；只有真实存在时才显示 Gemini 4 Argon，注入侧栏选择 Argon 时同步切换为它的独立额度。
- 智能账号推荐支持缺少周额度的情况，使用已确认的 5h 数据继续比较，不把未知额度当作 0%。

## 查询性能

- `loadCodeAssist` 在两个官方主机上并发解析账号真实项目。
- `retrieveUserQuotaSummary` 与 `fetchAvailableModels` 分阶段并发聚合，避免缺少一个字段时依次遍历真实项目、备用项目和虚拟项目。
- 本机当前账号的只读端到端测试由 9051ms 降至 4716ms；账号注册表与凭据文件前后 SHA-256 保持一致。
- 多账号仍并行刷新，并增加加载代次保护，旧请求不能覆盖用户新一轮刷新结果。

## 反馈与讨论

- 主反馈、系统公告和回复编辑器均支持文件选择与 `Ctrl+V` 粘贴图片；图片在主进程按文件头验证，限制为 PNG、JPG、GIF、WebP 且不超过 8MB。
- 回复数据结构增加图片字段，支持文字、图片或图文回复；失败后保留草稿并可重试。
- 列表先显示本地缓存并在后台同步，每次渲染 20 条，可继续加载，降低长列表首屏等待与滚动卡顿。
- 反馈卡片、作者信息、讨论线程、编辑器、图片预览、加载、空状态和错误状态统一为社区工作区设计，并适配深浅主题。

## 验证

- 单元测试覆盖：确认缺失后隐藏、主机失败时保留待确认、并发请求、非当前账号隔离、Argon 能力探测、图片文件头验证、剪贴板提取和图片回复契约。
- Chromium 页面冒烟验证加载状态可见、Gemini 周额度确认缺失后隐藏、Claude 周额度继续显示。
- 发布门禁包含补丁重建与校验、完整测试、安装升级测试、成品补丁 Worker 测试和动态汉化测试。
