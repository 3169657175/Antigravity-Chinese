# AGY Hub 1.4.6

> 发布日期：2026-11-14 · 适用平台：Windows 10 / 11 · 汉化补丁基于 Antigravity 2.32.1 验证

本次更新适配 Antigravity 2.32.1 的新版启动与界面结构，并继续完善主题背景和中文覆盖。

## 核心更新

- 主进程注入改用 `app.whenReady()` 生命周期语义定位，不再依赖容易变化的注释文本。
- Language Server 同时兼容旧版显式官方端点与 2.32.1 的官方 `baseLsArgs` 参数结构；无法识别时会在覆盖前安全停止。
- IPC 注入兼容新增的依赖参数签名，并保留账号、额度与网关配置隔离。
- 重新识别 2.32.1 的主内容根节点和 inset shell，恢复主题背景及输入区域的协调样式。
- 补齐新版问候语、自动化、自定义功能、设置、插件与加载状态等中文文案。
- 发布门禁包含语法检查、补丁完整性、升级安装、打包后补丁和动态翻译冒烟测试。

## 发布文件

- `agy-hub-setup-1.4.6.exe`
- `agy-hub-setup-1.4.6.exe.blockmap`

三个文件必须来自同一次构建并一同上传到 GitHub Release `v1.4.6`。
