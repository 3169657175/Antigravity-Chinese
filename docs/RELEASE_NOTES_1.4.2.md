# AGY Hub 1.4.2（本地构建，暂不发布 GitHub）

## 额度查询可靠性

- 当前账号使用本机 Antigravity 语言服务返回的有效额度桶作为优先来源；Cloud Code OAuth 额度为补充或回退。云端暂时缺失时保留可验证的本地额度。
- 语言服务启动超时短暂重试；短缓存按账号隔离，切换账号后失效，异步返回前二次确认当前账号没有变化。
- 不把未知额度渲染为 100%，不把未返回的 Argon 权限当作“不支持”。

## Gemini 4 Argon

- 当前账号：以真实 `gemini-argon-wtu-weekly` 额度桶为证据；非当前账号：使用该账号 OAuth 返回的专属额度桶或明确可见的 Argon 模型标识。
- 有明确证据才展示 Argon 独立区块。已知模型存在但额度尚未返回时标记“待确认”。未确认的账号不显示卡片，也不冒称该账号必定无权限。
- AGY Hub 与汉化注入包同步：多账号弹窗和侧栏保留账号级别额度，账号切换清理全局遗留额度，阻止旧请求回写新账号。
- 补充固定界面文案“Gemini 4 Argon Weekly Limit”的汉化。

## 验证与安全

- 不会自动切换账号或产生消耗模型额度的调用，不重启或注入正在使用的 Antigravity。
- 验证项目包括本地额度回退、云端能力识别、缓存按账号隔离、超时重试、局部缺失以及最终安装资源完整性。
- 本地安装包：`dist/agy-hub-setup-1.4.2.exe`，GitHub v1.4.1 仍为当前公开版本。
