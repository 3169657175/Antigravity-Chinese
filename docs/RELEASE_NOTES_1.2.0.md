# AGY Hub v1.2.0

本次更新重点提升了 Skill 管理体验、长对话反代稳定性和本地配置安全性。

- 重构 Skill 目录、分类和展示流程，让 Skill 市场在目录增长后仍能稳定加载、分页和自适应布局。
- 新增 Skill 中文简介增量翻译与缓存，只处理新增或发生变化的内容，减少重复请求和等待时间。
- 修复 Codex 与自定义 Responses Provider 在长对话自动压缩前可能出现的断流、上下文阈值不合理和压缩请求异常。
- 修复 Codex 模型目录与配置文件的发布竞态，避免配置重载时读取到缺失或未写完整的模型目录。
- 加强 Codex、Claude Code 和自定义 Provider 的账号、模型与路由隔离，测试操作不再影响当前正在使用的接入方式。
- 优化 MCP 检测、关键配置原子写入、损坏文件保护以及整体运行稳定性。

建议更新后重新打开 AGY Hub；如使用自定义 Provider，可在“反代接入”页面重新执行一次接入，让 Codex 读取最新的模型目录和长对话策略。
