## 接手时先看

- 账号或额度问题先分清 AGY Hub 界面与 Antigravity 注入界面。新版注入回归除了构建，还应执行注册函数，实际取到账号列表、额度处理函数和切换桥接。
- Codex 若提示模型目录 JSON 无法解析，先只读检查 `config.toml` 引用的目录文件是否完整。模型目录必须先写入并校验，再更新配置引用。长对话压缩沿用原生机制并按 Provider 选择窗口配置。
- 修改前查看工作树，保留用户未提交的更改。测试不切换活动账号、Provider 或网关模式。运行和发布是两条独立操作。
- 发布时用 GitHub Release 附件核对二进制，用标签对应的 Git 提交核对源码。两者分别核验，旧标签的更正需要明确记录。
