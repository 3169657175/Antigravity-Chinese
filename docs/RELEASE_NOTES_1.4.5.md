# AGY Hub 1.4.5

> 发布日期：2026-11-09 · 适用平台：Windows 10 / 11 · 汉化补丁基于 Antigravity 2.29.1 验证

本次更新重点修复 Antigravity 2.29.1 重构 Language Server 启动流程后汉化补丁无法注入、主内容区壁纸被遮挡，以及新版设置、自动化和自定义功能页面汉化不完整的问题。

## 核心更新

### 1. 适配 Antigravity 2.29.1

- 官方将同步 `shellEnvSync()` 改为异步 Shell 环境预取与 `await takeShellEnv()`。
- 汉化兼容构建不再依赖已经失效的固定单行锚点，改为识别 `process.env` 与登录环境的合并语义。
- 正确保留官方已经存在的异步 `startLanguageServer`，避免生成重复 `async` 关键字。

### 2. 提高后续版本容错能力

- 保留旧式同步环境合并的兼容路径，同时优先保证 2.29.1 的新版结构。
- 相近版本只要仍保留 Language Server 启动、官方端点和进程环境合并语义，即可自动适配。
- 如果官方彻底重写启动职责或出现多个不明确候选，构建会在覆盖客户端之前停止并给出诊断，不盲目写入 ASAR。

### 3. 发布与验证

- 使用本机官方 Antigravity 2.29.1 `app.asar` 完成隔离兼容构建。
- 保留官方原版、上一版汉化和失败回滚机制。
- 发布包包含完整安装程序、差分更新 blockmap 与 `latest.yml`，可用于覆盖安装和应用内升级。

### 4. 重新适配 2.29.1 主题与界面汉化

- 识别 2.29.1 新增的 `sidecars-view` 与主内容根节点结构，兼容根节点自身携带 `bg-background` 的情况，恢复首页、自动化和自定义功能页面的壁纸层。
- 新增“自动化任务 / Automations”视图识别，页面切换后会重新校验当前主区域，避免旧页面标记残留。
- 收敛 2.29.1 新版输入框的描边、阴影和圆角，保留轻量玻璃质感，不再出现突兀的双层高亮边框。
- 补齐新版动态问候、自动化空状态、自定义功能分类及可见插件说明，以及设置中的本机/远程权限、内置浏览器、下载位置、浏览历史等文案。
- 对官方 2.29.1 嵌入式前端执行只读文案审计，并增加专门回归测试；产品名、模型名、路径、代码和用户内容仍保持原文，避免误翻。

- `agy-hub-setup-1.4.5.exe.blockmap`
