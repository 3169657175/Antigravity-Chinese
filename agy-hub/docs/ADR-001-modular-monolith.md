# ADR-001：AGY Hub 采用模块化单体与显式边界

- 状态：已接受
- 日期：2026-07-26

## 背景

主进程、渲染进程、网关和样式曾分别集中在四个巨型文件中，导致修改一个页面或协议时容易影响其他功能。

## 决策

继续保持 Electron 模块化单体，不引入不必要的微服务；按业务域拆分 IPC、Controller、协议适配器和 CSS，并使用依赖注入保持模块可测试。

## 约束

- `main.js` 与 `renderer.js` 是组合根，不再接受大段新业务逻辑。
- 测试与接入必须语义分离。
- 三个网关 Profile 必须独立。
- CSS 按业务域保留职责边界，但 Electron 运行时必须加载完整根 `style.css`；禁止依赖 ASAR 内嵌套本地 `@import`。
- 通过 `architectureBoundaries.test.js` 固化行数预算和入口依赖。

## 后果

优点：定位更快、回归范围更小、模块可单测、新对话 AI 更容易找到正确文件。  
代价：入口文件和模块之间需要显式传递依赖，新增脚本时必须维护 `index.html` 和运行依赖测试；CSS 在缺少可靠 bundler 的阶段需要同时维护职责模块与完整运行时文件，并通过打包产物验证防止漂移。
